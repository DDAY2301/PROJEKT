# Project Visibility Sprint

Spletna stran za ponudbo hitre izdelave projektnih spletnih strani in diseminacijskih paketov za Erasmus+, CERV in druge evropske projekte.

## Objava

Javna stran je v mapi `dist`. GitHub Pages jo objavi samodejno ob spremembi veje `main`.

## Domena

Predvidena glavna domena je `projectvisibility.eu`. Domena se registrira in podaljšuje ločeno. Datoteko `CNAME` dodamo šele po nakupu domene in pred vklopom lastne domene v GitHub Pages.

## Lokalni pregled

Odprite `dist/index.html` v brskalniku. Stran nima zunanjih knjižnic ali gradnikov.
